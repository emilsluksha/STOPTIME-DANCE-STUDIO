# STOPTIME Dance Studio

Сайт студии STOPTIME (Даугавпилс). Статический HTML/CSS/JavaScript без сборки.

GitHub Pages: Settings > Pages > Deploy from a branch > main / root.

## Структура

Первый экран со слоганом и записью → Aktualitātes → Par mums → LMDA → Kontakti.
Направления танцев, филиалы и прежние показатели сохранены в раскрывающемся блоке Par mums.
Исходные цвета и надпись STOPTIME сохранены. По запросу владельца заголовки используют афишный Barlow Condensed, основной текст — Manrope, логотип — Unbounded. Дополнения к стилям и состояния наведения/фокуса находятся в updates.css.
Все шрифты сохранены локально в assets/fonts вместе с лицензиями: для их загрузки не требуется подключение к Google Fonts.
В Aktualitātes пока размещена существующая информация о жизни студии, направлениях и LMDA: даты и новости не выдуманы. Эти три карточки можно заменить реальными публикациями в index.html. Запись на пробную тренировку открывается только с первого экрана. Показатель «400+ dejotāju studijā» предоставлен владельцем.
Фото для фонового баннера не предоставлено: сохранён исходный фон.

## Заявки на пробную тренировку

Кнопка открывает анкету на латышском. Заявки направляются через FormSubmit на **gribudejot_stoptime@inbox.lv** (без обратных слешей). Адрес задан в applicationEmail в site-config.js; адрес обработчика формируется из него автоматически. Общий контактный адрес stop_time@inbox.lv в разделе Kontakti сохранён отдельно.

### Обязательная активация получателя

1. Отправьте одну заявку с сайта через HTTP/HTTPS (не через file://). При необходимости пройдите проверку от спама на странице FormSubmit.
2. Откройте почту gribudejot_stoptime@inbox.lv и найдите письмо активации от FormSubmit, включая папку «Спам».
3. Нажмите ссылку подтверждения в письме. Без подтверждения получателя доставка заявок не активирована.
4. Отправьте ещё одну проверочную заявку и убедитесь, что она появилась в почте. Повторите проверку после публикации на постоянном домене: может потребоваться подтверждение формы с нового адреса сайта.

Документация: https://formsubmit.co/ и https://formsubmit.co/help

Отправка — обычный HTTPS POST на https://formsubmit.co/gribudejot_stoptime@inbox.lv. Браузер переходит на страницу сервиса для проверки/подтверждения. reCAPTCHA не отключена. Передаются поля name, email, phone, city, style, message, consent, _subject, _honey. Адрес посетителя используется для ответа; копии на другие адреса не настроены. Анкета указывает, что отправка выполняется через FormSubmit. Сайт не выдаёт переход к сервису за подтверждение доставки в почтовый ящик.

### Альтернативный обработчик

Чтобы использовать Formspree или собственный сервер, измените deliveryMode на "ajax" и укажите formEndpoint. Контракт: POST multipart/form-data с Accept: application/json, успешный HTTP 2xx только после принятия заявки, поддержка CORS. Поля: name, email, phone, city, style, message, consent, subject, _gotcha. Получатель в этом режиме настраивается на стороне сервиса/сервера; applicationEmail задаёт запасной адрес для ручной связи. Обработчик должен проверять поля, ограничивать запросы и отправлять письма на сервере. При пустом endpoint используется явно обозначенная подготовка письма в почтовой программе.

Не добавляйте пароли почты или секретные ключи в файлы сайта. Браузерный тест перехватывает запрос FormSubmit и проверяет точный адрес назначения, метод POST и состав полей. Реальная отправка, активация и получение письма в ящике при локальной проверке не выполнялись.
