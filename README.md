# STOPTIME Dance Studio

Сайт студии STOPTIME (Даугавпилс). Статический HTML/CSS/JavaScript без сборки.

GitHub Pages: Settings > Pages > Deploy from a branch > main / root.

## Структура

Первый экран со слоганом и записью → Aktualitātes → Par mums → LMDA → Kontakti.
Направления танцев, филиалы и прежние показатели сохранены в раскрывающемся блоке Par mums.
Исходные цвета и надпись STOPTIME сохранены. По запросу владельца заголовки используют афишный Barlow Condensed, основной текст — Manrope, логотип — Unbounded. Дополнения к стилям и состояния наведения/фокуса находятся в updates.css.
Все шрифты сохранены локально в assets/fonts вместе с лицензиями: для их загрузки не требуется подключение к Google Fonts.
В Aktualitātes пока размещена существующая информация о жизни студии, направлениях и LMDA: даты и новости не выдуманы. Эти три карточки можно заменить реальными публикациями в index.html. Запись на пробную тренировку открывается только с первого экрана. Показатель «400+ dejotāju studijā» предоставлен владельцем.
Фото для фонового баннера не предоставлено: сохранён исходный фон.

## Анкета и доставка вложений — Google Apps Script

FormSubmit удалён из рабочего кода. Поля: имя, фамилия, обязательный телефон, один заполненный DOC/DOCX/PDF до 5 МБ и согласие. Оригинальный бланк лежит в assets/documents/iesniegums-2026-2027.docx; он скопирован без изменения содержимого.

Письмо на gribudejot_stoptime@inbox.lv содержит только имя, фамилию и вложение. Телефон проверяется, но не сохраняется и не включается в письмо по запросу владельца. Посетителю показано, что телефон нужно указать также в самом документе. Убедитесь, что бланк содержит контактный телефон.

### Однократное подключение (без Google Sheets)

1. Откройте https://script.google.com/home/start и создайте проект «STOPTIME applications».
2. Замените всё содержимое Code.gs кодом из google-apps-script/Code.gs. Сохраните.
3. В настройках проекта можно включить показ appsscript.json и заменить его предоставленным файлом с минимальным разрешением на отправку почты.
4. Deploy → New deployment → тип Web app. Execute as: Me. Who has access: Anyone (именно без обязательного Google-аккаунта).
5. Нажмите Deploy. Владелец Google-аккаунта должен лично подтвердить разрешение на отправку почты. Скрипт не запрашивает чтение Gmail или доступ к Google Drive. Не предоставляйте доступ незнакомому коду; здесь используйте свой проект с проверенным Code.gs.
6. Скопируйте Web app URL, заканчивающийся на /exec, в formEndpoint в site-config.js. Секреты не нужны.
7. Загрузите изменённые index.html, site.js, site-config.js, updates.css и assets/documents в существующий GitHub Pages репозиторий. Домен менять не требуется.
8. Откройте опубликованный сайт, скачайте бланк, заполните тестовыми данными и отправьте. Проверьте полученное письмо и возможность открыть вложение в gribudejot_stoptime@inbox.lv (включая спам). Только это подтверждает фактическую доставку.

При изменении Code.gs: Deploy → Manage deployments → Edit → New version → Deploy, чтобы сохранить прежний /exec URL.

### Как работает отправка

Обычный POST в скрытый iframe Google Apps Script; никакого fetch с mode: no-cors и предположений об успехе. doPost проверяет поля и размер/сигнатуру файла, вызывает MailApp.sendEmail с реальным вложением, затем возвращает postMessage с уникальным номером заявки. Сайт принимает только ответ с домена Google и совпадающим случайным номером. При ошибке или отсутствии подтверждения 90 секунд данные и выбранный файл остаются в форме.

Google принимает письмо к отправке, но такой ответ не подтверждает получение Inbox.lv. Скрипт сохраняет только номера принятых заявок на 7 дней и счётчик отправок для повторных попыток без дубликатов. Между отправкой письма и записью номера остаётся небольшое окно при аварии сервиса; абсолютная exactly-once доставка почты не обещается. Документы и телефоны не записываются в Drive/Sheets.

Лимит скрипта: 80 писем/день, дополнительно действует квота MailApp вашего аккаунта. При достижении лимита показана ошибка и адрес для ручной отправки. Есть honeypot и проверка времени заполнения; они не заменяют полноценную защиту от целевого спама. Публичный endpoint можно вызывать извне: список origin — проверка маршрута ответа, не аутентификация.

### Проверки

Запуск из корня проекта: node tests/backend.cjs (либо задайте SITE_ROOT). Проверяются точные байты вложения, адрес назначения, состав письма, повторная отправка, ошибки почтового сервиса, квоты, обязательные поля, недопустимые файлы. Тест не отправляет настоящую почту. Старый browser.cjs проверял FormSubmit и заменён новой проверкой.

До заполнения formEndpoint сайт честно сообщает, что отправка ещё не подключена. Настоящая доставка считается проверенной только после публикации скрипта и получения тестового письма.
